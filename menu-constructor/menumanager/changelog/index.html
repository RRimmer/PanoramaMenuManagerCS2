Ядро

Core

Плагин MenuManagerCore и библиотека MenuManagerApi. После замены DLL нужен полный перезапуск сервера.

The MenuManagerCore plugin and the MenuManagerApi library. After replacing a DLL, restart the server.

1.1.10

  • Открытый выпадающий список помечается на обёртке строки. Сама строка не растягивается и не сдвигает соседние пункты.
  • An open dropdown is marked on the row wrapper. The row itself does not stretch or push the items around it.

1.1.8

  • AddSelect открывает список до 12 значений. Длиннее 12 остаётся подменю.
  • Смена настройки не возвращает панораму на первую страницу. Страница сбрасывается, когда меню закрыли.
  • AddSelect opens a list of up to 12 values. Longer lists stay a submenu.
  • Changing a setting does not send panorama back to page 1. The page resets when the menu is closed.

1.1.7

  • В MenuManagerCore.json поле Notifications. По умолчанию уведомления включены.
  • В !menu, если выбран тип Панорама, игрок включает или выключает уведомления только себе. Выбор сохраняется.
  • MenuManagerCore.json has Notifications. Notifications are on by default.
  • In !menu, when the type is Panorama, a player turns notifications on or off for themselves. The choice is saved.

1.1.6

  • Слайдер и разбор «название: вкл/выкл» живут внутри MenuManagerCore. Старая MenuManagerApi.dll больше не роняет !menu, !admin и !vip.
  • На сервере одна копия API: shared/MenuManagerApi/MenuManagerApi.dll. css_plugins reload старую сборку не выгружает.
  • The switch and “name: on/off” parsing live inside MenuManagerCore. An older MenuManagerApi.dll no longer takes down !menu, !admin and !vip.
  • Keep one API copy at shared/MenuManagerApi/MenuManagerApi.dll. css_plugins reload does not unload the assembly already in memory.

1.1.5

  • AddToggle рисует слайдер. Текст «Имя: Вкл/Выкл» тоже становится слайдером.
  • Notify показывает тост: успех, внимание, ошибка.
  • AddToggle draws a switch. Text shaped like “Name: On/Off” becomes a switch too.
  • Notify shows a toast: success, warning, error.

1.1.4

  • Меню не открывается в том же кадре, что команда. Это убирает кик NETWORK_DISCONNECT_OVERFLOW.
  • The menu does not open on the same tick as the command. That avoids the NETWORK_DISCONNECT_OVERFLOW kick.

1.1.3

  • Тип меню PanoramaMenu. В конфиге по умолчанию "DefaultMenu": "PanoramaMenu".
  • Menu type PanoramaMenu. The config default is "DefaultMenu": "PanoramaMenu".

Сайт

Site

Конструктор и страницы для тех, кто ставит форк или пишет свой плагин.

The constructor and the pages for people installing the fork or writing a plugin.

  • Конструктор цветов, размеров, слайдеров и выпадающего списка. Скачиваются ui.css и menu_ui.xml.
  • Русский и английский. Язык запоминается.
  • Страница API с примерами: меню, слайдер, список и тост. Автор форка — E!N, ссылки на оригинал оставлены.
  • Кнопки API и «Список изменений» открывают index.html, чтобы страница работала на хостинге без индекса каталога.
  • Constructor for colors, sizes, switches and the dropdown. It downloads ui.css and menu_ui.xml.
  • Russian and English. The language is remembered.
  • API page with examples: menu, switch, list and toast. The fork author is E!N, and the links to the original stay.
  • The API and Changelog buttons open index.html, so the page works on a host that does not serve a directory index.

Панорама

Panorama

Клиентский аддон: menu_ui.xml и ui.css. После замены игрок должен зайти на сервер заново.

The client addon: menu_ui.xml and ui.css. After a replacement the player has to rejoin.

1.1.10

  • Список рисуется поверх соседних строк. Строка остаётся высотой 40px и не накрывает их своим фоном.
  • У нижних пунктов список открывается вверх, сама строка не уезжает.
  • У каждого пункта списка свой текст. Раньше все строки копировали текущее значение.
  • The list draws on top of the rows around it. The row stays 40px and its background does not cover them.
  • Rows near the bottom open the list upward. The row itself stays put.
  • Each dropdown entry has its own text. Before, every row copied the current value.

1.1.8

  • Список до 12 значений открывается на месте, без захода в подменю.
  • У уведомления есть значок: галочка, восклицательный знак или крестик. Значок нарисован панелями, не символом шрифта.
  • A list of up to 12 values opens in place, without entering a submenu.
  • The toast has an icon: check, exclamation or cross. The icon is drawn with panels, not a font glyph.

1.1.5

  • В меню появились слайдер и тост справа сверху.
  • The menu gained a switch and a toast at the top right.
