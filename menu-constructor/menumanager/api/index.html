С чего начать

Getting started

MenuManagerApi — библиотека, через которую другие плагины открывают меню игрока. Внешний вид панорамы настраивается конструктором и не требует правок в чужом плагине. Твой код описывает пункты, а MenuManager рисует чат, WASD, HTML или панораму — то, что игрок выбрал в !menu.

MenuManagerApi is the library other plugins use to open a player menu. Panorama colors come from the constructor and do not need changes in your plugin. Your code describes the rows. MenuManager draws chat, WASD, HTML or panorama, whichever the player picked in !menu.

В проекте плагина добавь ссылку на уже стоящую на сервере DLL. Свою копию в папку плагина не клади.

Reference the DLL that already lives on the server. Do not ship a second copy inside your plugin folder.

<ItemGroup>
  <Reference Include="MenuManagerApi">
    <HintPath>game\csgo\addons\counterstrikesharp\shared\MenuManagerApi\MenuManagerApi.dll</HintPath>
  </Reference>
</ItemGroup>

Куда класть DLL

Where the DLL goes

На сервере должна быть одна MenuManagerApi.dll:

The server needs exactly one MenuManagerApi.dll:

addons/counterstrikesharp/shared/MenuManagerApi/MenuManagerApi.dll

Копия в plugins/MenuManagerCore, plugins/IksAdmin или plugins/VIPCore перекрывает shared и ломает меню. css_plugins reload старую сборку из памяти не выгружает. После замены API нужен полный перезапуск сервера.

A copy in plugins/MenuManagerCore, plugins/IksAdmin or plugins/VIPCore shadows the shared one and breaks menus. css_plugins reload does not unload the assembly already in memory. After replacing the API, restart the server.

menu:nfcore

MenuManager публикует API способностью menu:nfcore. Забирай её, когда все плагины уже загружены. Если MenuManager ещё не встал, Get() бросит исключение — поймай его и оставь запасной чат или HTML.

MenuManager publishes the API as the menu:nfcore capability. Take it after every plugin has loaded. If MenuManager is not installed, Get() throws. Catch that and keep a chat or HTML fallback.

using CounterStrikeSharp.API.Core.Capabilities;
using MenuManager;

private static readonly PluginCapability<IMenuApi?> MenuApi = new("menu:nfcore");
private IMenuApi? _menu;

public override void OnAllPluginsLoaded(bool hotReload)
{
    try { _menu = MenuApi.Get(); }
    catch { _menu = null; }
}

GetMenu

IMenu GetMenu(string title, Action<CCSPlayerController>? backAction = null,
    Action<CCSPlayerController>? resetAction = null);

IMenu GetMenuForcetype(string title, MenuType type,
    Action<CCSPlayerController>? backAction = null,
    Action<CCSPlayerController>? resetAction = null);

GetMenu открывает тот тип, который выбран у игрока. GetMenuForcetype фиксирует тип. ButtonMenu в forcetype всё равно следует меню по умолчанию сервера, чтобы старые плагины вроде IksAdmin попадали в панораму.

GetMenu uses the type the player selected. GetMenuForcetype pins a type. A forced ButtonMenu still follows the server default, so older plugins such as IksAdmin land on panorama.

backAction вызывается кнопкой «Назад». resetAction вызывается, если у меню PostSelectAction.Reset. NewMenu и NewMenuForcetype оставлены только для старого кода, в новом плагине их не вызывай.

backAction runs from the Back button. resetAction runs when the menu uses PostSelectAction.Reset. NewMenu and NewMenuForcetype exist for old code. Do not call them from a new plugin.

IMenu menu = api.GetMenu("Магазин", backAction: OpenMain);
menu.PostSelectAction = PostSelectAction.Nothing;
menu.Open(player);

PostSelectAction.Nothing оставляет меню открытым после клика. Так делают переключатели: обработчик сам рисует меню заново. Close закрывает меню. Панорама при повторном открытии того же заголовка остаётся на той же странице, пока игрок не закроет меню крестиком.

PostSelectAction.Nothing leaves the menu open after a click. Toggles use this and redraw the menu themselves. Close closes it. Panorama keeps the same page when the same title opens again, until the player closes the menu.

Ещё на API есть CloseMenu, GetMenuType и HasOpenedMenu.

The API also has CloseMenu, GetMenuType and HasOpenedMenu.

AddMenuOption

ChatMenuOption AddMenuOption(string display,
    Action<CCSPlayerController, ChatMenuOption> onSelect,
    bool disabled = false);

Обычный пункт. В панораме это кнопка со стрелкой, она открывает следующее меню из onSelect. Цвета чата в панораме снимаются, текст остаётся.

A normal row. In panorama this is a button with an arrow. onSelect opens the next menu. Chat colors are stripped in panorama. The text stays.

menu.AddMenuOption("Оружие", (player, _) => OpenWeapons(player));
menu.AddMenuOption("Скоро", (_, _) => { }, disabled: true);

Строка, которая начинается с невидимого символа \u200B, никогда не станет слайдером. Так помечают пункт «Категория: Выкл», если это переход в подменю, а не переключатель.

A row that starts with the invisible character \u200B is never treated as a switch. Use that for a “Category: Off” row that opens a submenu instead of toggling.

AddToggle

ChatMenuOption AddToggle(IMenu menu, string label, bool on,
    Action<CCSPlayerController, ChatMenuOption> onSelect,
    bool disabled = false);

В панораме рисуется слайдер. label — имя без «Вкл/Выкл». on — текущее положение. В чате, WASD и HTML тот же пункт остаётся текстом, если ты сам допишешь состояние. На старой API метода нет: проверяй его через отражение или лови отсутствие и рисуй «Имя: Вкл».

Panorama draws a switch. label is the name without On/Off. on is the current state. Chat, WASD and HTML still show text, so append the state yourself for those types. An old API has no method. Probe it with reflection, or catch the miss and draw “Name: On”.

bool enabled = GetSetting(player) != "off";
api.AddToggle(menu, "Броня", enabled, (p, _) =>
{
    SetSetting(p, enabled ? "off" : "on");
    OpenMenu(p);
});

Панорама и сама узнаёт слайдер по тексту Имя: Вкл или Name: Off. Подходят слова on, off, вкл, выкл, açık, acik, kapalı, kapali. Звёздочка в конце снимается. Одно слово «Вкл» без двоеточия слайдером не становится.

Panorama also detects a switch from text like Name: On or Имя: Выкл. The words are on, off, вкл, выкл, açık, acik, kapalı, kapali. A trailing star is ignored. A lone “On” without a colon is not a switch.

AddSelect

ChatMenuOption AddSelect(IMenu menu, string label, string value, string[] choices,
    Action<CCSPlayerController, ChatMenuOption, int> onSelect,
    bool disabled = false);

Выпадающий список в панораме. label — имя слева, value — текст текущего значения справа, choices — пункты списка. В onSelect приходит индекс выбранного пункта. Список от 1 до 12 значений. Длиннее 12 панорама показывает как обычную кнопку: для такого случая открой подменю через AddMenuOption.

A panorama dropdown. label is the name on the left, value is the current text on the right, choices are the entries. onSelect receives the chosen index. The list must have 1 to 12 entries. More than 12 is drawn as a normal button, so open a submenu with AddMenuOption instead.

В чате и WASD выпадающего списка нет. Перед вызовом проверь GetMenuType(player) == MenuType.PanoramaMenu. Иначе построй обычный список кнопок.

Chat and WASD have no dropdown. Check GetMenuType(player) == MenuType.PanoramaMenu before calling this. Otherwise build a normal list of buttons.

string[] fov = ["Выкл", "50", "60"];
string current = fov[index];
if (api.GetMenuType(player) == MenuType.PanoramaMenu)
{
    api.AddSelect(menu, "Угол обзора", current, fov, (p, _, picked) =>
    {
        ApplyFov(p, picked == 0 ? "off" : fov[picked]);
        OpenMenu(p);
    });
}
else
{
    menu.AddMenuOption($"Угол обзора: {current}", (p, _) => OpenFovSubmenu(p));
}

Строка списка не прыгает вверх. Список рисуется поверх соседних пунктов. У нижних строк он открывается вверх.

The row does not jump. The list draws on top of the rows around it. Rows near the bottom open upward.

Notify

void Notify(CCSPlayerController player, string title, string text,
    MenuNotice notice = MenuNotice.Success);

enum MenuNotice { Success, Warning, Error }

Тост справа сверху. Success — галочка, Warning — восклицательный знак, Error — крестик. Значки нарисованы в панораме, не символами шрифта. Тост живёт около 3 секунд и не пропадает вместе с меню.

A toast at the top right. Success is a check, Warning is an exclamation mark, Error is a cross. The icons are drawn by panorama, not by font characters. The toast stays for about 3 seconds and does not hide when the menu closes.

Тост есть только у панорамы. Он не показывается, если в MenuManagerCore.json стоит "Notifications": false, или игрок выключил уведомления в !menu → Панорама. По умолчанию они включены. Для чата пиши сообщение сам.

The toast exists only for panorama. It is hidden when MenuManagerCore.json has "Notifications": false, or when the player turned notifications off in !menu → Panorama. They are on by default. For chat, print the message yourself.

if (api.GetMenuType(player) == MenuType.PanoramaMenu)
    api.Notify(player, "Броня", "Броня → Вкл", MenuNotice.Success);
else
    player.PrintToChat(" Броня → Вкл");

MenuType

enum MenuType
{
    Default = -1,
    ChatMenu = 0,
    ConsoleMenu = 1,
    CenterMenu = 2,
    ButtonMenu = 3,
    MetamodMenu = 4,
    PanoramaMenu = 5
}

PanoramaMenu — кликабельный диалог. На одной странице 6 пунктов. ButtonMenu и MetamodMenu — меню на WASD. CenterMenu — HTML по центру. Игрок меняет тип командой !menu.

PanoramaMenu is the clickable dialog. One page holds 6 rows. ButtonMenu and MetamodMenu are the WASD menu. CenterMenu is centered HTML. The player changes the type with !menu.

Как рисует панорама

How panorama draws

  • Файлы menu_ui.xml и ui.css лежат в клиентском аддоне MultiAddonManager. После замены игрок должен зайти на сервер заново.
  • Слайдер: AddToggle или текст «Имя: Вкл/Выкл».
  • Список: AddSelect, не больше 12 пунктов. Строка остаётся на месте.
  • Стрелка: обычный AddMenuOption.
  • Повторное открытие меню с тем же заголовком сохраняет страницу. Крестик сбрасывает её на первую.
  • Меню не открывается в том же кадре, что команда. Это защита от кика NETWORK_DISCONNECT_OVERFLOW.
  • menu_ui.xml and ui.css live in the MultiAddonManager client addon. After a replacement the player has to rejoin.
  • Switch: AddToggle, or the text “Name: On/Off”.
  • Dropdown: AddSelect, at most 12 entries. The row stays put.
  • Arrow: a normal AddMenuOption.
  • Opening the same title again keeps the page. The close button returns it to the first page.
  • The menu does not open on the same tick as the command. That avoids the NETWORK_DISCONNECT_OVERFLOW kick.

Целый пример

Full example

Команда !shop открывает слайдер и список. Для чата список становится подменю.

The !shop command opens a switch and a list. On chat, the list becomes a submenu.

using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Core.Capabilities;
using CounterStrikeSharp.API.Modules.Commands;
using CounterStrikeSharp.API.Modules.Menu;
using MenuManager;

public class ShopPlugin : BasePlugin
{
    public override string ModuleName => "Shop";
    public override string ModuleVersion => "1.0.0";
    public override string ModuleAuthor => "You";

    private static readonly PluginCapability<IMenuApi?> MenuApi = new("menu:nfcore");
    private IMenuApi? _menu;
    private readonly Dictionary<ulong, bool> _armor = new();

    public override void Load(bool hotReload)
    {
        AddCommand("css_shop", "Shop", OnShop);
    }

    public override void OnAllPluginsLoaded(bool hotReload)
    {
        try { _menu = MenuApi.Get(); }
        catch { _menu = null; }
    }

    private void OnShop(CCSPlayerController? player, CommandInfo info)
    {
        if (player == null || !player.IsValid || _menu == null) return;
        Open(player);
    }

    private void Open(CCSPlayerController player)
    {
        var api = _menu!;
        ulong id = player.SteamID;
        bool armor = _armor.TryGetValue(id, out bool on) && on;
        IMenu menu = api.GetMenu("Магазин");
        menu.PostSelectAction = PostSelectAction.Nothing;

        api.AddToggle(menu, "Броня", armor, (p, _) =>
        {
            _armor[p.SteamID] = !_armor.GetValueOrDefault(p.SteamID);
            if (api.GetMenuType(p) == MenuType.PanoramaMenu)
                api.Notify(p, "Броня", _armor[p.SteamID] ? "Вкл" : "Выкл",
                    _armor[p.SteamID] ? MenuNotice.Success : MenuNotice.Warning);
            Open(p);
        });

        string[] fov = ["Выкл", "50", "60"];
        if (api.GetMenuType(player) == MenuType.PanoramaMenu)
        {
            api.AddSelect(menu, "Угол обзора", "Выкл", fov, (p, _, index) =>
            {
                api.Notify(p, "Угол обзора", fov[index]);
                Open(p);
            });
        }
        else
        {
            menu.AddMenuOption("Угол обзора: Выкл", (p, _) => OpenFov(p, fov));
        }

        menu.Open(player);
    }

    private void OpenFov(CCSPlayerController player, string[] fov)
    {
        IMenu menu = _menu!.GetMenu("Угол обзора", backAction: Open);
        foreach (string choice in fov)
            menu.AddMenuOption(choice, (p, option) => p.PrintToChat(option.Text));
        menu.Open(player);
    }
}
